サブスク健全性

RevenueCat v2 から契約を 1 行 = 1 契約で取り込み、日次スナップショットとして残します。チャーン率は「月初のアクティブ数に対する当月の解約数」で固定し、分母の取り違えが起きない形にしています。

  • 月次売上（ストア別） — App Store / Play Store を積み上げで比較
  • チャーン率 — ストア別・契約期間別（月額 / 年額）
  • 再登録・復帰 — 一度解約した会員の戻り
  • キャンセル率の注意線 — 30% を超えると画面上で状態が変わる

課金導線

GA4 のイベント（navigate_to_purchase の source / screen_type）を BigQuery から集計し、「どの画面から課金画面に来て、どれだけ完了したか」を導線ごとに出します。

  • 導線別 CV 表 — 到達数・完了数・CV 率を導線名で
  • 日次トレンド — 直近 30 日の導線別の推移
  • チケット / プレミアム — 画面種別で分けて比較

経営サマリー

月で締める画面です。ストア手数料（15% / 30%）と返金を差し引き、AdMob の広告収益を合算した手取りを、ソース別に並べます。任意期間の指定はできません — 月次の締めに他の窓の意味論を混ぜないためです。

  • 売上の内訳と手取り — 売上 → 手数料 → 返金 → 広告 → 手取りのウォーターフォール
  • 会員数の増減ブリッジ — 月初 → 新規 → 復帰 → 解約 → 月末
  • 手取り推移 — サブスク / チケット / 広告を直近 6〜12 ヶ月で
