1. はじめに

株式会社リアルバインド（以下「当社」）は、当社が提供するアプリ運用ダッシュボードサービス「Fireboard」（以下「本サービス」）における利用者情報の取り扱いについて、本プライバシーポリシー（以下「本ポリシー」）を定めます。

2. 取得する情報および取得方法

本サービスは、利用者が連携を許可した範囲で、以下のデータを各サービスの API 経由で取得します。取得はすべて読み取り専用で行い、本サービスから連携先のデータを変更・削除することはありません。

  • Google Analytics 4 / BigQuery: 利用者の Firebase Analytics（GA4）から BigQuery にエクスポートされたイベントデータ（イベント名、パラメータ、擬似ユーザー ID、日時）。Google アカウントの認可（OAuth 2.0）またはサービスアカウントで取得します。
  • Firestore: 利用者が指定した Firebase プロジェクト内のコレクション（ユーザーログ、残高台帳、消費ログ等）。会話・メッセージの本文は取得しません。Google アカウントの認可またはサービスアカウントで取得します。
  • AdMob: 広告収益のレポート（日次の収益、インプレッション）。Google アカウントの認可で取得します。
  • RevenueCat: サブスクリプション契約の状態、プラン、購入履歴、ストア別の売上。RevenueCat アカウントの認可（OAuth 2.0）で取得します。
  • アカウント情報: 本サービスへの登録時に取得する Google アカウントのメールアドレスと表示名。

3. 利用目的

取得したデータは、以下の目的にのみ利用します。

  • 本サービスのダッシュボード上での指標算出、グラフ・表の表示
  • 取り込み処理の実行記録、障害調査、不具合対応（利用者からの問い合わせ対応を含む）
  • 本サービスのアカウント管理、利用者への連絡

上記以外の目的（広告配信、第三者への販売、本サービスと無関係な分析、AI モデルの学習等）には利用しません。

4. 保存期間

取得したデータは、ダッシュボードの時系列表示に必要な期間に限り、当社のデータベースに日次スナップショットとして保存します。利用者が連携を解除した場合（Google アカウントまたは RevenueCat の設定からアクセス権を取り消した場合）、または削除の依頼を受けた場合は、合理的な期間内に該当データを削除します。

5. 第三者提供

当社は、法令に基づく場合を除き、取得したデータを本人の同意なく第三者に提供することはありません。本サービスの提供のために利用するクラウド基盤（データベース・実行環境）への保存は、第三者提供に該当しません。

6. Google API から取得したデータの取り扱い

Fireboard's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

具体的には、Google API から取得した利用者データを、広告目的での利用、第三者への販売、人間による閲読（利用者の同意がある場合、セキュリティ上必要な場合、法令に基づく場合を除く）、生成 AI モデルの学習には供さず、本サービスの機能提供に必要な範囲でのみ利用します。

7. アクセス権の取り消し

利用者は、以下の Google アカウントの設定ページから、本サービスに付与したアクセス権をいつでも取り消すことができます。RevenueCat のアクセス権は、RevenueCat の設定画面または本サービスの設定画面から取り消せます。

  • Google アカウント — サードパーティのアクセス権

8. 本ポリシーの変更

当社は、必要に応じて本ポリシーの内容を変更することがあります。重要な変更を行う場合は、本ページ上での告知その他適切な方法により周知します。
